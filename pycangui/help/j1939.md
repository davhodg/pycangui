# J1939

The **J1939** pane lists nodes (NAME from address claims), faults -- active
from DM1, previously active from DM2 -- with lamp status, and reassembled multi-packet messages (TP.BAM / TP.CM via
python-can-j1939). Claim a tester address to send requests and multi-packet PGNs; a
J1939 DBC (`VFrameFormat=J1939PG`) is matched by PGN so SPNs land in Signals
and Plot. DM1/DM2 faults show the failure mode in words -- "voltage too low" rather
than "FMI 4" -- next to the SPN.

**Claim address** takes the tester address beside it on the bus: 0xF9 unless
you change it, and remembered. A claim takes a moment, because the address is
announced and then held open for anybody with a better claim to it. The button
reads **Release 0xF9** once the address is pycangui's, and the Event Log says so
if it is already in use. Without a claim pycangui sends from the null address
0xFE, which does for requests and single frames; a message longer than eight
bytes needs the claim. **Request address claims**, beside it, asks every node to
say who it is, which fills the node list without waiting for each to speak.

**Request** asks one node, or every node, for a parameter group. The list has
the ones worth asking for -- DM1 active faults, DM2 previously active, DM3
and DM11 to clear them, DM4 freeze frames, DM5 readiness, and ECU, software
and component identification -- and any other PGN can be typed in hex. The
destination is *Global* or one of the nodes seen. Every request says what came
of it in the Event Log: each node's answer, decoded -- the faults of DM1 and
DM2, or that there are none, the fields of the identification, DM4 and DM5 --
the acknowledgement a clear gets back, accepted or refused, a node refusing a
request it will not answer, and, when the 1.25 s a node has to answer is up,
that nobody did. A node answers once in the log however often it broadcasts
the same PGN; DM1 and DM2 also go into the fault table, marked active or
previously active.
DM3 and DM11 erase what a node holds, so they ask first, whether picked from
the list or typed. A long answer to one node comes back only once pycangui
has claimed an address, since a node cannot hold a conversation with 0xFE.

**Send PGN** sends one, to a destination and at a priority, which is 6 unless
you change it. The node list shows each node's NAME, decoded, and when it was
last seen.

**Stop broadcasts** is DM13: the nodes stop sending their periodic messages,
which quietens a busy bus or one being flashed. It asks first, and holds: a
node starts again by itself six seconds after it last heard the hold, so
pycangui repeats it every four seconds until **Start broadcasts**. It goes to
the destination chosen for Request, which is usually *Global*.

The J1939 name tables live in [`hooks/j1939.py`](hooks.md), the PGN names and the failure modes are there to read, and
adding a proprietary PGN or one of the failure modes SAE leaves reserved is a line in a dictionary. Load a J1939 DBC to name them, or add
the ones you care about to `SPN_NAMES`. 

The demo device includes an engine at SA 0. It broadcasts EEC1, CCVS1 and
DM1, and answers every request in the list: its identification as multi-packet
BAM transfers, a previously active fault in DM2, its readiness in DM5, and DM3
and DM11 with an acknowledgement -- after DM3 its DM2 is empty.
